**An Instructional Design Solution for Schools Experiencing Teacher Shortages.**

A flagship instructional-design portfolio project: a complete Grade 5 English Language Arts
**hybrid learning ecosystem** engineered so rigorous, standards-aligned instruction continues
no matter who is in the room — the regular teacher, a substitute, or the student learning
independently.

---

## 📘 Project Overview
This is not a set of lesson plans — it is a **digital learning ecosystem**. Every lesson is a
complete multimedia module designed to run in **four delivery models**: face-to-face,
synchronous online, asynchronous, and hybrid. The project demonstrates district-level
curriculum design, multimedia and AI-enhanced content, interactive learning, embedded
assessment, and a leader-facing implementation strategy.

## 🎯 The Educational Challenge
Teacher and substitute shortages interrupt instruction, fracture curriculum consistency, and
widen learning gaps. This project reframes that operational crisis as an **instructional design
problem** and solves it by decoupling instruction from any single expert in the room.

## 🧠 Instructional Design Philosophy
Grounded in **ADDIE**, **Backward Design**, the **Gradual Release of Responsibility**, and
**Universal Design for Learning** — and informed by cognitive-load, retrieval-practice, and
worked-example research. AI accelerates production; educators review every output.

## ✨ Features
- **10 pages** — Home, Challenge, Framework, Units, Lessons, Teacher Center, Student Center,
  Assessment, Implementation, and a Reflection case study.
- **6 fully specified units** with essential questions, standards, objectives, success criteria,
  vocabulary, performance tasks, assessments, differentiation, extensions, and pacing.
- **2 fully built multimedia sample lessons** with:
  - an **AI-generated instructional video** (self-contained animated player with browser
    narration, always-on captions, and in-video interaction points)
  - a **complete AI production package** (narration script, storyboard, slide/image prompts,
    visual design guide, voice/music/SFX recommendations, and production workflow)
  - interactive activities: quizzes, flashcards, fill-in-the-blank, drag-and-drop, and reading
    annotation — all with instant feedback
  - mini-lesson, guided/independent practice, discussion (per delivery model), differentiation
    (5 learner profiles), assessment + rubric, parent support, extensions, teacher notes, and a
    **delivery-model comparison table**
- **Assessment system** — diagnostic, formative, summative, reading/writing rubrics, peer &
  self-assessment, feedback templates, and a growth dashboard with achievement badges.
- **Downloadable resources** — lesson plan, teacher guide/answer key, and student handouts
  (editable Markdown), plus client-generated video transcripts and one-click Print/Save-as-PDF.
- **Accessibility** — UDL throughout, keyboard support, captions, reduced-motion, printable
  fallbacks, and color-plus-text feedback.

## 🛠️ Technology Stack
| Tech | Role |
|------|------|
| HTML5 | Semantic structure |
| CSS3 | Custom premium design system, Grid/Flexbox, responsive, print styles |
| Vanilla JavaScript | All interactivity (tabs, quizzes, video player, dashboard, downloads) |
| Web Speech API | In-browser narration for the instructional videos |
| localStorage | Progress, badges, reflections (no server, no login) |
| GitHub Pages | Free static hosting |

No frameworks, no build step, no dependencies.

## ▶ How to Run Locally
- **Quickest:** double-click `index.html`.
- **Recommended preview:** `python -m http.server 8000` then open `http://localhost:8000`.

## 🚀 GitHub Pages Deployment
1. Push these files to a GitHub repo (root).
2. Repo **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**.
3. Live at `https://<username>.github.io/<repo>/`. Every `git push` republishes automatically.

## 🏫 How Schools Could Use This Curriculum
- Run as core Grade 5 ELA instruction, or as a continuity plan for absences and vacancies.
- Hand a substitute a ready-to-run, rigorous lesson (see the Substitute Quick-Start).
- Embed modules in any LMS (Google Classroom, Canvas, Schoology, Moodle).
- Adopt the implementation plan, PD model, and ROI case for system-level rollout.
